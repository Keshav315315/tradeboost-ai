# TradeBoost.AI 🚀

An intelligent stock market learning and virtual trading platform for Indian markets.

## Features
- 📈 Virtual Trading Simulator with real NSE prices
- 🤖 AI Mentor powered by GPT-4
- 📚 8 Learning Sections with quizzes
- 🏆 Weekly Simulator League with rewards
- 🛡️ Stop Loss & Target Price alerts
- 📊 Portfolio tracking with P&L analysis

## Tech Stack
- React + Vite
- Supabase (Auth + Database)
- OpenAI GPT-4o-mini
- Finnhub API (Stock data)
- TailwindCSS

## Setup
1. Clone the repo
2. Run: npm install
3. Copy .env.example to .env
4. Add your API keys in .env
5. Run: npm run dev

## Environment Variables
See .env.example for required keys.
